# Full UI review — agent-board

**Date:** 2026-11-08<br>
**Scope:** every visible board panel, base and dialogs, at widths
320, 390, 640, 768, 1280 and 1680 px; light and dark theme; keyboard/focus; empty
state, long content and real data.<br>
**Method:** Playwright/Chrome on the running app, with console, overflow,
accessible names, tap targets, focus and before/after screenshots.<br>
**Workflow:** Elixir Agent Kit 0.8.0 `responsive-layout` (large), with
accessibility and async state checks.

## Fixed findings

| Sev. | Finding | Fix |
|---|---|---|
| P1 | At 768 px the 64 px rail cut off the labels and the bottom navigation buttons; navigation became unreachable | Up to 900 px the rail gives way to the native `ab-mobilebar`, with the same destinations |
| P1 | On phone/tablet the mobilebar hid `.ab-repo__name`; the repositories became empty 16×14 px buttons | Labels restored in the mobilebar and items 44 px tall |
| P1 | Superagentes, Atalhos, Voz and Configurações (Superagents, Shortcuts, Voice, Settings) existed only in the rail; on the phone there was no way to open them | The mobilebar gained the four destinations with stable IDs and focus returned on close |
| P1 | Inspector tabs hid `PR` at 1280 px | Tabs now wrap (and keep a minimum target) |
| P2 | Focus went back to `body` when closing a panel opened from the mobilebar | Buttons with `id` + `data-board-menu`; focus returns to the summary/origin button |
| P2 | The composer header wrapped the repository chip onto two lines and the close button fell to the left | Header on one line on the phone, chip with ellipsis, close on the right |
| P2 | Agent messages had a huge gap because the markup template injected whitespace inside `white-space: pre-wrap` | Markup now builds escaped HTML without template whitespace; a test covers escaping and the absence of space |
| P2 | The dialog could open outside the viewport while the hook called `showModal()` | `dialog[open]` fixed and centered also in the non-modal state |
| P2 | The "Reconectado" (Reconnected) toast covered the composer/conversation footer | Toast hidden while a dialog or the inspector is open |
| P2 | Settings fields were 32 px on the phone | 40 px up to 900 px |
| P3 | Small buttons ("Dispensar" — dismiss, "Novo pedido" — new request, workers) below 32–40 px | 40 px/32 px targets on phone and tablet |

## Residual (not changed in this round)

- The static labels of `intake`, `activity`, `ai`, `history` and the board's
  flashes were translated; only technical terms remain (PR, sync, IA).
- Inline PR links in the summary have a 24 px target (WCAG 2.2 minimum); they
  are not a primary tap target like the buttons.
- "Resumo do dia" (Day summary) is still global, but now identifies itself as
  "do board" ("from the board").
- I did not run write flows (send request, save settings, speak), because they
  are real actions; the review was read-only/safe interaction.
- Contrast was measured with axe-core 4.10.2 in light and dark on the main
  panels: zero WCAG 2.2 AA violations after the fixes.
- A physical on-device keyboard (iOS/Android) was not emulated; the width matrix
  and the keyboard test were done in Chrome.
- Screen readers (VoiceOver/NVDA) and physical devices were not exercised.
