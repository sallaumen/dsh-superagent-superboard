## Achados corrigidos

| Sev. | Achado | Correção |
|---|---|---|
| P1 | Em 768 px o rail de 64 px cortava os rótulos e os botões de navegação inferiores; a navegação ficava inalcançável | Até 900 px o rail dá lugar ao `ab-mobilebar` nativo, com os mesmos destinos |
| P1 | No telefone/tablet o mobilebar escondia `.ab-repo__name`; os repositórios viravam botões vazios de 16×14 px | Rótulos restaurados no mobilebar e itens com 44 px de altura |
| P1 | Superagentes/Atalhos/Voz/Configurações só existiam no rail; no telefone não havia como abri-los | Mobilebar ganhou os quatro destinos com IDs estáveis e foco devolvido ao fechar |
| P1 | Abas do inspetor escondiam `PR` em 1280 px | Abas passaram a quebrar linha (e mantêm alvo mínimo) |
| P2 | Foco voltava para `body` ao fechar um painel aberto pelo mobilebar | Botões com `id` + `data-board-menu`; foco volta ao resumo/botão de origem |
| P2 | Cabeçalho do compositor quebrava o chip do repositório em duas linhas e o botão fechar caía à esquerda | Cabeçalho em uma linha no telefone, chip com ellipsis, fechar à direita |
| P2 | Mensagens do agente tinham um vão enorme porque o template do markup injetava whitespace dentro de `white-space: pre-wrap` | Markup passou a montar HTML escapado sem whitespace de template; teste cobre escape e ausência de espaço |
| P2 | Diálogo podia abrir fora da viewport enquanto o hook chamava `showModal()` | `dialog[open]` fixo e centralizado também no estado não-modal |
| P2 | Toast “Reconectado” cobria o rodapé do compositor/conversa | Toast oculto enquanto um diálogo ou o inspetor está aberto |
| P2 | Campos de Configurações tinham 32 px no telefone | 40 px até 900 px |
| P3 | Botões pequenos (Dispensar, Novo pedido, workers) abaixo de 32–40 px | Alvos de 40 px/32 px no telefone e tablet |

## Residual (não alterado nesta rodada)

- `intake`, `activity`, `ai` e partes de `history` ainda misturam rótulos em
  inglês com a UI em português. É decisão de produto/localização, não um
  defeito de layout.
- Links de PR inline no resumo continuam com alvo de 16 px de altura; são
  links de texto, mas não são alvo primário de toque.
- O “Resumo do dia” é global e aparece também em repositório vazio; o rótulo
  não diz que é do board. Mantido para não quebrar o contrato/testes atuais;
  é uma decisão de produto pendente.
- Não executei fluxos de escrita (enviar pedido, salvar configuração, falar),
  por serem ações reais; a revisão foi de leitura/interação segura.
- Contraste não foi medido por axe/Lighthouse; foi inspecionado visualmente em
  claro e escuro.
- Teclado virtual físico (iOS/Android) não foi emulado; a matriz de largura e
  o teste de teclado foram feitos no Chrome.
