# Bug audit — connection errors and app flows

**Date:** 2026-11-09<br>
**Scope:** the running board (one LiveView at `/` with panels in the query
string, the JSON API, the supervised processes) and the live service log.<br>
**Method:** the live log read back to its start (78k lines, 2026-11-05 to
2026-11-09); a worktree server on port 4700 against a *copy* of the dev database,
without GitHub or model keys, driven by headless WebKit over a URL matrix and
every safe control; a read-only static pass whose findings were kept as
hypotheses until reproduced.<br>
**Workflow:** Elixir Agent Kit 0.8.0 `debugging` (large).

The live service on 4099 and its database were only read. Red actions were not
executed against GitHub or the runner.

## States

`investigating` · `confirmed` · `fixed` (code and test) · `validated` (seen
working in the running app) · `blocked`.

## Details

### B01

- **Flow:** opening Logs, or any URL with `panel=logs`.
- **Reproduce:** a board log holding a byte that is not UTF-8, then `/?panel=logs`.
- **Expected:** the sheet lists warnings and errors.
- **Observed:** `NOT-CONNECTED` for 30 s, more than 200 reconnects per URL, 425
  `GenServer terminating` in three minutes of sweep.
- **Evidence:** live log, 2026-11-09 09:58:47 on: `(Jason.EncodeError) invalid
  byte 0xE3` in `"… a voz não foi gerada (HTTP 400)"`, from
  `Phoenix.Socket.V2.JSONSerializer`, label `Phoenix.LiveView, BoardLive`, last
  message `show_panel logs` or the `phx_join` of `?panel=logs`.
- **Cause:** two owners. `launchd` starts the service without a locale, so the
  BEAM's standard output is Latin-1 (`env -i elixir` reports `:latin1`, with
  `LANG=en_US.UTF-8` `:unicode`), and `AgentBoard.Logs` handed those bytes to
  the socket as text. The URL keeps the panel, so each reconnect joined and
  crashed again until the tab was closed.
- **Fix:** `Logs` reads a line that is not UTF-8 as Latin-1, so the bytes
  already in the file open too; `scripts/service.sh` sets `LANG`.
- **Validated:** `logs_test.exs` and `logs_panel_test.exs` (failed before);
  on the running app, a copy of the real log opens with 127 entries, one socket
  and no crash. The service only picks up `LANG` at its next restart.

### B02

- **Flow:** the sheet is open and a superagent changes state (ticker, every 30 s).
- **Observed:** `FunctionClauseError` in `Phoenix.Component.assign/2`, last
  message `:superagents_changed`.
- **Cause:** `assign(:logs_sources, ...)` without the socket in
  `BoardLive.handle_info(:superagents_changed, ...)`.
- **Fix and validation:** the socket is passed; `logs_panel_test.exs` failed
  before. On the running app, a state change during an open sheet leaves it
  connected.

### B03

- **Flow:** `/?repo[a]=b`, `/?repo[]=x`, `task[a]=1`, an id past bigint, a NUL
  byte in the slug.
- **Expected:** the board opens without the panel.
- **Observed:** 500 from the dead render (`String.split/3`, `String.Chars`,
  `DBConnection.EncodeError`, `Postgrex.Error`).
- **Cause:** the URL reached the database layer unchecked.
- **Fix:** `Board.repository_by_slug/1` takes only a usable string and
  `Board.parse_id/1` is the one reader of an outside id (navigation, `open_any`,
  `PATCH /api/tasks/:id`).
- **Validated:** `board_url_params_test.exs` (14 URLs) and the same URLs on the
  running app.

### B04

- **Flow:** on Hoje, click the project the board last showed.
- **Observed:** nothing happens, and the rail marks that project as current.
- **Cause:** the "same repository" guard in `handle_event("select", ...)` did
  not look at the view.
- **Fix and test:** `today_test.exs`.

### B05

- **Flow:** any board load where a workpad has no validation.
- **Evidence:** `FunctionClauseError` in `LocalCI.workpad_state(nil, sha)`, ten
  times in the live log on 2026-11-08 and 09.
- **State:** already fixed on `main` before this audit (`workpad_status(nil, _)`);
  the sweep over real data did not hit it.

### B06

- **Flow:** a comment or body on a `ready` task quoting
  `https://github.com/a/b/pull/9999999999`, or a ticket following that thread.
- **Observed (test):** `DBConnection.EncodeError` from the int4 `number` columns,
  inside the load that every page runs.
- **Cause:** numbers read from text went to queries unchecked.
- **Fix:** `GitHub.number/1` is the one reader of a number from text or from the
  runner (`Board`, `Workpad`, `Attribution`, `LocalCI`, `AgentState`).
- **Validated:** `board_workpad_test.exs`, `github_number_test.exs`. Not seen in
  real data; found by reading and reproduced in a LiveView test.

### B07

- **Flow:** the runner's JSON with a field in another shape: a non-numeric channel
  number, `assignments` as an object, `ended` or a report as text, a summary that
  is not text.
- **Observed (test):** `ArgumentError`, `BadMapError` or `FunctionClauseError`
  during every load, for every repository.
- **Cause:** `AgentState.normalize/1` trusted the shape of data another program
  owns and versions.
- **Fix:** a field in another shape reads as absent; the row stays.
- **Validated:** `agent_state_test.exs`, `board_workpad_test.exs`. Not seen in
  real data.

### B08

- **Flow:** a superagent manager answering `/state` with something that is not the
  expected object (a proxy's HTML, `{"health":{"uptime":3}}`).
- **Observed (reading):** the exception runs in a `Task.async_stream` task linked
  to the ticker, whose `rescue` cannot catch an exit; the ticker restarts and
  ticks after 1 s, past the supervisor's limit of three restarts in five seconds.
- **Fix:** `DshManager.observation/1` answers an observed error.
- **Validated:** `superagents_test.exs` (the shape). The supervisor cascade was
  not run.

### Rejected

A commit subject that is not UTF-8 reaching the running card was a candidate of
the same family as B01. Git converts such a message to UTF-8 when it commits
(the regression test passed without any fix), so no change was made.
